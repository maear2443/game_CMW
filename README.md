# Totem Drop

**1분 아케이드 모바일 게임** - 불량 블럭만 제거하라!

## 게임 소개

무한히 이어지는 토템 블럭 기둥이 1분 동안 천천히 아래로 내려옵니다. 플레이어는 불량 블럭만 망치로 제거하여 빈 칸을 즉시 메우며, 정확도와 반응속도로 점수를 겨룹니다.

### 핵심 특징

- **1분 타임어택**: 빠른 플레이 세션
- **간단한 조작**: 터치/클릭으로 블럭 제거
- **난이도 곡선**: 시간이 지날수록 속도와 난이도 증가
- **콤보 시스템**: 연속 정확 타격으로 보너스
- **리더보드**: 글로벌/주간 랭킹 (추후 확장)

## 기술 스택

- **엔진**: PixiJS 7.x
- **언어**: TypeScript
- **빌드**: Vite
- **PWA**: Service Worker + Manifest
- **타겟**: 모바일 웹 (iOS/Android)

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 http://localhost:3000 열기

### 3. 프로덕션 빌드

```bash
npm run build
```

빌드 결과는 `dist/` 폴더에 생성됩니다.

### 4. 빌드 미리보기

```bash
npm run preview
```

## 프로젝트 구조

```
/public
  index.html          # 메인 HTML
  manifest.json       # PWA 매니페스트
  sw.js              # 서비스 워커
  /assets            # 에셋 (이미지, 사운드)
    /sprites
    /sfx
    README.md        # 에셋 가이드

/src
  main.ts            # 메인 진입점

  /engine            # 엔진 코어
    app.ts           # PixiJS 앱 초기화
    rng.ts           # 시드 가능 난수 생성기
    pool.ts          # 오브젝트 풀링

  /game              # 게임 로직
    types.ts         # 타입 정의
    config.ts        # 게임 설정/상수
    state.ts         # 게임 컨트롤러 (상태 머신)
    column.ts        # 블럭 스폰/관리
    scoring.ts       # 점수 시스템
    input.ts         # 입력 처리
    sound.ts         # 사운드 시스템

    /ui              # UI 컴포넌트
      hud.ts         # HUD (점수, 타이머)
      menu.ts        # 메뉴 화면
      result.ts      # 결과 화면

  /net               # 네트워크
    api.ts           # 리더보드 API

  /utils             # 유틸리티
    rect.ts          # 충돌 판정
```

## 게임 규칙

### 점수 시스템

- **양품 안전 통과**: +5점
- **불량 제거 성공**: +8점
- **불량 미처리 통과**: -10점
- **양품 오제거**: -12점

### 콤보 보너스

- 5콤보: +5점
- 10콤보: +15점
- 20콤보: +40점

### 난이도 단계

| 시간 | 속도 | 불량 확률 |
|------|------|-----------|
| 0~15초 | 100 px/s | 30% |
| 15~35초 | 110 px/s | 40% |
| 35~55초 | 120 px/s | 50% |
| 55~60초 | 130 px/s | 60% |

## 확장 가능성

### 에셋 시스템

현재는 플레이스홀더 그래픽을 사용하지만, 다음과 같이 확장 가능:

1. **토템 조합 시스템**: 눈/입/무늬 파츠를 조합하여 다양한 블럭 생성
2. **파티클 이펙트**: 제거/통과 시 화려한 효과
3. **망치 커스터마이징**: 다양한 망치 스킨

### 사운드

`public/assets/sfx/` 폴더에 실제 오디오 파일 추가 후 `src/game/sound.ts`에서 로드

### 리더보드

백엔드 API 구현 예시는 설계 문서의 "부록 B" 참조

## 성능 최적화

- **오브젝트 풀링**: 블럭 생성/파괴 최소화
- **텍스처 아틀라스**: 스프라이트 일괄 드로우
- **60FPS 타겟**: 저사양에서는 30FPS 어댑티브
- **모바일 최적화**: 터치 입력, 뷰포트 스케일링
