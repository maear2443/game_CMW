# 사운드 에셋

이 폴더에 게임에서 사용할 사운드 파일을 넣어주세요.

## 필요한 사운드 파일

### BGM (배경음악)
- `bgm_menu.mp3` - 메뉴 화면 BGM
  - 시간: 루프 가능하도록 제작
  - 형식: MP3 또는 OGG
  - 용량: 3MB 이하 권장

- `bgm_game.mp3` - 게임 플레이 중 BGM
  - 시간: 60초 이상 (루프)
  - 형식: MP3 또는 OGG
  - 용량: 5MB 이하 권장
  - 템포: 빠른 느낌 (긴장감)

### 효과음
- `sfx_hit_perfect.mp3` - PERFECT 타격음
  - 시간: 0.2초 이하
  - 느낌: 높은 톤, 반짝임

- `sfx_hit_excellent.mp3` - EXCELLENT 타격음
  - 시간: 0.2초 이하
  - 느낌: 중간 톤

- `sfx_hit_good.mp3` - GOOD 타격음
  - 시간: 0.2초 이하
  - 느낌: 일반적인 타격음

- `sfx_hit_notbad.mp3` - NOT BAD 타격음
  - 시간: 0.2초 이하
  - 느낌: 낮은 톤

- `sfx_miss.mp3` - 실수 (양품 제거)
  - 시간: 0.3초 이하
  - 느낌: 부정적인 소리

- `sfx_pass_bad.mp3` - 불량 통과 (패널티)
  - 시간: 0.3초 이하
  - 느낌: 경고음

- `sfx_countdown.mp3` - 카운트다운 (3, 2, 1)
  - 시간: 0.5초 이하
  - 느낌: 짧은 삑 소리

- `sfx_start.mp3` - 게임 시작
  - 시간: 1초 이하
  - 느낌: 긍정적인 시작음

## 사운드 제작 가이드

### 오디오 설정
- 샘플레이트: 44100Hz
- 비트레이트: 128kbps ~ 192kbps
- 채널: 스테레오
- 형식: MP3 (호환성 최고)

### 볼륨 가이드
- BGM: -20dB ~ -15dB (배경으로 은은하게)
- 효과음: -10dB ~ -5dB (명확하게 들림)

### 현재 상태
파일이 없으면 Web Audio API로 생성된 프로시저럴 사운드가 사용됩니다.
