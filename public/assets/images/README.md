# 이미지 에셋

이 폴더에 게임에서 사용할 이미지 파일을 넣어주세요.

## 필요한 이미지 파일

### 블럭 이미지
- `block_good.png` - 양품 블럭 (파란색 원통형)
  - 권장 크기: 120x120 픽셀
  - 형식: PNG (투명 배경)

- `block_bad.png` - 불량 블럭 (빨간색 원통형 + X 표시)
  - 권장 크기: 120x120 픽셀
  - 형식: PNG (투명 배경)

### 배경 이미지 (선택사항)
- `background.png` - 게임 배경
  - 권장 크기: 540x960 픽셀
  - 형식: PNG 또는 JPG

## 이미지 제작 가이드

### 블럭 디자인 팁
- 원통형 모양 (3D 느낌)
- 밝은 색상 사용 (가독성)
- 외곽선 추가 (명확한 구분)
- 그림자 효과 (입체감)

### 현재 상태
파일이 없으면 코드로 생성된 기본 그래픽이 사용됩니다.
