# 에셋 폴더 구조

이 폴더에는 게임에 필요한 모든 에셋 파일을 배치합니다.

## 필요한 에셋 목록

### 1. 스프라이트 (sprites/)

#### 블럭 이미지
- `block_good.png` (120x120px) - 양품 블럭
- `block_bad.png` (120x120px) - 불량 블럭
- 추후 확장: 토템 파츠별 조합 시스템
  - `totem_eyes_1.png` ~ `totem_eyes_5.png`
  - `totem_mouth_1.png` ~ `totem_mouth_5.png`
  - `totem_pattern_1.png` ~ `totem_pattern_5.png`

#### UI 요소
- `hammer.png` (64x64px) - 망치 커서 (선택)
- `icon-192.png` (192x192px) - PWA 아이콘 (소)
- `icon-512.png` (512x512px) - PWA 아이콘 (대)

### 2. 사운드 (sfx/)

#### 효과음
- `hit_good.mp3` - 불량 블럭 제거 성공음
- `hit_bad.mp3` - 양품 블럭 오타격음
- `pass_good.mp3` - 양품 안전 통과음
- `pass_bad.mp3` - 불량 블럭 미처리 통과음
- `combo.mp3` - 콤보 달성음

#### 배경음악
- `bgm.mp3` - 게임 플레이 BGM (30~60초 루프)

## 플레이스홀더 상태

현재는 코드에서 플레이스홀더 그래픽을 생성하여 사용합니다:
- 양품 블럭: 초록색 사각형
- 불량 블럭: 빨간색 사각형
- 사운드: 간단한 비프음 생성

## 에셋 추가 방법

1. 위 목록에 맞춰 파일을 준비
2. 해당 폴더에 배치
3. `src/game/state.ts`의 `createPlaceholderAssets()` 메서드를 실제 에셋 로드로 교체
4. 사운드는 `src/game/sound.ts`에서 로드 및 재생

## 에셋 제작 가이드

### 블럭 디자인
- 크기: 120x120px
- 형식: PNG (투명 배경 가능)
- 스타일: 토템 폴 느낌, 눈/입/무늬로 양품/불량 구분
- 색상: 양품은 밝고 따뜻한 색, 불량은 어둡거나 금이 간 느낌

### 사운드 디자인
- 형식: MP3 또는 OGG
- 길이: SFX는 0.1~0.5초, BGM은 30~60초 루프
- 볼륨: 모바일 스피커 고려, 과도하게 크지 않게

### 아이콘
- PWA 아이콘은 심플하고 식별 가능한 디자인
- 배경: 불투명 (#1a1a2e 추천)
